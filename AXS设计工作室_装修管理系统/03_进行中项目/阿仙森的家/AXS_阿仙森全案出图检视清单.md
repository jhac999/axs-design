## 1. 标配必出图（核心动线基准库 - 6张）
*说明：此模块用于确立全屋设计骨架，重点展示核心动线与高频生活场景。*
- [x] **01. 客厅全景** 
  - *空间作用*：定调全屋主视角，展示家庭核心社交区、电视背景与沙发比例，体现待客排面与整体审美。
- [x] **02. 客餐厅一体** 
  - *空间作用*：展示LDK（客餐厨）大空间的洄游动线与空间纵深，验证整体通透感与动线流畅度。
- [x] **03. 入户玄关** 
  - *空间作用*：体现归家第一视角的落尘区、鞋帽收纳极限吞吐量，以及环境心理学中的气口缓冲风水。
- [x] **04. 主卧** 
  - *空间作用*：展示私密深度睡眠区的静谧感、全遮光系统落地及核心衣物收纳效率。
- [x] **05. 厨房** 
  - *空间作用*：验证洗切炒黄金三角动线、高低台面人体工学尺寸，及大型家电内嵌落位。
- [x] **06. 公卫** 
  - *空间作用*：展示干湿分离逻辑、客用洗漱区防隐私死角及家政洁具系统收纳。
