# AXS Skill: 客户数据扫描与物理建模 (Client Data Acquisition)

## 1. 核心定位
**医学级物理参数扫描仪 (无本地极客引擎轻量版)**。
全面废弃本地极客 H5 表单。前端唯一入口为本地化 H5 文件 `AXS_设计工作室客户需求深度调研表.html`。本模组负责通过“潜意识探测”与“机电限界拷问”，将客户需求强制映射为可落地的建筑物理参数。

## 2. 系统执行红线 (Blockers)
- 🚫 **无黑绿报文不立项**：客户未在 H5 页面中点击提交并生成黑绿配色的终端报文，绝不允许开启后续 CAD 绘制流程。
- 🚫 **严禁感性审美黑话**：全面封杀“奶油风”、“北欧风”等无效词汇。系统只识别 m³(收纳容积)、K(色温)、mm(净空) 等硬核参数。

## 3. 标准操作流 (SOP)
### 3.1 本地端轻量化下发与回收
- **触达与下发**：微信直发 H5 链接，附带话术：“请花 5 分钟完成系统扫描，以获取您的专属空间物理矩阵。”
- **潜意识探雷提取**：
  - 触发疲劳度：识别客户进门动线，若极度排斥家务，启动【家务全自动协议】。
  - 触发视觉洁癖：若要求“眼不见心不烦”，启动【极简隐藏协议】（微水泥+无踢脚线工艺）。
- **物理与机电限界拷问**：
  - 容积测试：强制客户勾选巨型障碍物（行李箱/洗地机/囤积品），系统按基数 (2m³) + 倍率叠加计算最少隐藏容积。
  - 机电底线：是否强依赖全屋地暖/中央空调/新风，以此锚定顶部净高折损率。

### 3.2 初始技术规格书生成 (Data Output)
H5 引擎将在本地直接渲染出一份《初始技术规格书》，客户需截图或复制文本回传。内容结构必须如下：
```text
> DEEP_PSYCHOLOGY_ANALYSIS (心理痛点层)
视觉容忍度: 极低 (强制隐形)

> HARDCORE_PHYSICAL_PARAMS (建筑物理层)
[容积矩阵] 强制收纳基数 >= 4.5 m³ 
[光电矩阵] 强制锁定 3500K 防眩光洗墙 (Ra>95)
[空间矩阵] 顶面约束: 零跌级全平大平顶 

> MEP_SYSTEMS (机电装备要求)
[环控] 必须地暖 + 中央空调
```
收到该报文，进入【02 效果图及方案引擎】。
