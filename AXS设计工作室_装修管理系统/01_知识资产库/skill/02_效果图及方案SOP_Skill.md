# AXS Skill: 方案推演与三重模型交付引擎 (Render & PPT SOP)

## 1. 核心定位
**Python 驱动的三重模型生成器**。
彻底废弃“本地生成的 16:9 物理 PPTX”提案。系统将直接调用本地 Python 引擎 (`build_ppt_presentation.py`)，将酷家乐/CAD的视觉产物，与问卷中的心理/物理数据全自动封装为极致的 16:9 本地 PPTX 文件。

## 2. 出图数量与机位红线 (Render Checklist)
- 🚫 **严禁凑数出图**：200㎡ 基准项目，出图总数严格锁定在 **11-13 张**。
- 🚫 **严禁上帝视角**：所有渲染机位高度必须锁定在 **1.1m - 1.5m**，使用 35mm-50mm 焦段，严禁超广角畸变。
- **LDK核心区 (3张)**：全局正视、功能反打、局部收口特写。
- **主卧套房 (3张)**：睡眠区正视、洄游动线视角、精神角落特写。
- **厨卫次卧 (各1张)**：一图尽览空间定调，不做赘述。

## 3. 四步状态机交付环 (The 4-Step Python Loop)
完全摒弃微信决选单，状态确认改为微信点对点“落子无悔”式确认：
1. **Node 1: Layout (平面骨架)** - 发送带有彩色分区底纹的 CAD PDF。确认后，墙体拆改量与第一笔首付款锁定。
2. **Node 2: Style (风格皮肤)** - 确认天地墙主材体系（微水泥/涂料/木饰面）。
3. **Node 3: Soft (软装落位)** - 确认家具尺寸、布艺色彩。
4. **Node 4: MEP (机电与五金)** - 确认开关点位与隐藏收纳内部分割。

## 4. 三重模型 PPT 排版铁律
执行 `py build_ppt_presentation.py` 必须遵守以下 16:9 画幅硬性切分：
- **【左侧 60% 屏幕】 美学层 (Aesthetics)**：只放无损高清效果图，不加任何水印，绝对的极简留白。
- **【右上侧 20% 屏幕】 心理层 (Psychology)**：使用金色或白色字体，提取问卷痛点作为文案标题（如：“针对您的视觉洁癖，我们消灭了这堵墙”）。
- **【右下侧 20% 屏幕】 数据层 (Data System)**：使用黑底绿字，硬性罗列支撑该美学视角的建筑机电参数（如：隐藏收容体积 2.5m³，洗墙色温锁定 3500K，净空 2850mm）。
