# 🚀 AXS 系统运营总纲 (Anti-Gravity 工作流)

> **“让机器与代码去穿越泥泞，让主理人永远端坐云端，运筹帷幄。”**

AXS（Aesthetics × System）（美学 × 系统）

> **【AXS 核心三大总则】**
> **1. 极致的实用性**
> **2. 极致的简约**
> **3. 智能系统 1.0 辅助**

## 🎭 一、 核心角色与职能切割 (Role & Separation)

本系统最核心的护城河，在于绝对的“脑手分离”，杜绝主理人陷入具体实操的泥潭：

* **👑 主理人 (云端指挥官)：** 坚守高维视角。只负责系统规则（SOP与代码逻辑）的捍卫、核心美学体系的把控、优质供应链资源的录入。绝对不向下兼容泥水与粉尘的具体执行，也**绝不向任何第三方 SaaS 平台（如飞书、酷家乐）低头妥协**。
* **👷 现场执行人 (物理督导)：** 作为代码系统在物理世界的“肉身化身”。负责处理线下高摩擦事务，拍摄隐蔽工程特写，并将冰冷的系统指令转化为有温度的现场沟通。

## ⚙️ 二、 去 SaaS 化：纯本地底层工具链 (Tech Stack)

系统已全面摒弃飞书、酷家乐等臃肿的第三方平台，采用“纯本地极客驱动 (Local-Geek-Driven)”架构，数据 100% 掌握在自己手中：

1.  **🌐 H5 数据探针 (Frontend)：** 系统的“交互触角”。轻量化 H5 问卷直接发给客户，采集潜意识需求，通过 Webhook 瞬间传入本地主机。
2.  **🧠 Antigravity 解析中枢 (Brain)：** 本地化 AI 核心。读取 H5 数据，利用《V1.0 需求映射表》自动算出演算结果，推导收纳体量与机电红线。
3.  **🎨 Python 视觉引擎 (Aesthetics)：** 斩断酷家乐依赖。结合底层 CAD 骨架，全自动生成 11-13 张带有“心理痛点靶向”和“工程数据参数”的满编制 16:9 物理 PPT。
4.  **💰 本地算量与报价引擎 (Costing)：** 监听 CAD 变动，自动读取 `axs_cad_bridge.py` 提取的面积，比对本地《材料底价库》，强行剥离 10% 服务费，生成去伪存真的透明决选 PPT。
5.  **💬 微信原生闭环 (Communication)：** 斩断飞书打扰。所有由系统自动生成的精美 PPT 提案、报价单，直接通过微信发送给客户，实现最低摩擦的沟通与确认。
6.  **🗄️ Obsidian：** 系统的“唯一真相源 (SSOT)”。存储所有 Markdown 格式的标准工艺（SOP）、需求映射表与底层物料库。
7.  **👁️ 4G AI 摄像头：** 系统的“无感传感器”。全天候抓拍工地实景，为本地 AI 监理提供客观数据。

## 🔄 三、 Agentic 运营闭环与自适应生命周期 (Agentic Loop)

系统采用高度工程化的 Agent 模式运作，将项目生命周期划分为四个明确流转的闭环阶段：

### 阶段 1：规划模式 (PLANNING) —— 意图编译与约束设定
* **工作逻辑：** 整合客户提交的《AXS 客户需求深度调研表》（H5 导出的客观物理参数 MD）与《AXS 审美与需求探测引擎 1.0》（对话式 AI 导出的主观潜意识 JSON） ➔ 解析中枢将两份双源数据进行深度结合，并自动交叉匹配 `01_知识资产库/设计理念库` 中的设计美学与功能性文献 ➔ 自动编译并输出最终的《设计用户审美习惯与日常生活白皮书》，硬性锁定“红线约束（Restrictions）”与“终极痛点”。
* **系统流转：** 将客户的物理空间指标与感官敏感度共同翻译为底层空间布局与光照指令，实现设计前的精细化对齐。
* **产出：** 确立 10% 固管服务费规则，输出《设计用户审美习惯与日常生活白皮书》，锁定设计边界。

### 阶段 2：执行模式 (EXECUTION) —— 双重代码编译与物料合成
* **工作逻辑：** 方案获准 ➔ 视觉引擎并行渲染 ➔ Python 算量中枢介入，提取 CAD 边界尺寸 ➔ 自动编译生成 AutoLISP 精确结构代码及包含 11 张核心机位 PPT。
* **系统流转：** 主理人一键向客户推送 100% 零差价的《透明决选报价单 PPT》及 CAD 代码指引。
* **产出：** 消除传统采购差价，用纯代码透明度换取资金的绝对授权。

### 阶段 3：验证模式 (VERIFICATION) —— 物理 Walkthrough 与工序核验
* **工作逻辑：** 施工进场 ➔ 4G AI 摄像头抓拍/现场执行人特写上传 ➔ 本地 AI 对照 Obsidian 标准工艺（SOP）进行像素级对齐验证。
* **系统流转：**
    * **✅ 验证通过：** 自动生成工序 Walkthrough，微信端无声推送客户，自动释放节点资金。
    * **❌ 验证失败（发现 bug）：** 系统触发红线熔断，自动向执行人手机甩出带代码框的限期整改令。
* **产出：** 实现全天候物理世界与代码标准的对齐验证。

### 阶段 4：反思与数据回流 (REFLECTION) —— 错题沉淀与自主进化
* **工作逻辑：** 触发阶段验收或遇到重大违规整改（返工） ➔ 主理人与执行人启动“复盘反思” ➔ 提炼出本项目的工艺缺陷、材料损耗及供应链踩坑点，归纳为 Obsidian 工艺库中的 `gotchas.md` (避坑指南)。
* **系统流转：** 自动更新 01_知识资产库 的底价表和标准工艺规范，使系统在下次 PLANNING 阶段能自动规避类似问题。
* **产出：** 财务结算闭环，AXS 本地系统完成自主学习与版本迭代。

## 🛡️ 四、 系统防错机制与红线防御 (Safeguards)

1.  **红线熔断器 (Restrictions Guard)：** 客户 H5 探针中的“绝对不要”项在 Python 视觉和算量脚本中作为硬编码约束，一旦检测到渲染或报价中包含红线物料，直接报错中断生成。
2.  **供应链保质期 (SKU Melt)：** Obsidian 材料库内嵌价格有效期监控，过期 SKU 在报价中自动熔断，确保生成的每个数字绝对安全。
3.  **微信防伪墙 (Truth Ledger)：** 废除云端协同。所有图纸、报价 PPT 全部以微信留痕作为物理实体交互，主理人坚守隔离圈，杜绝线下摩擦污染云端规则。
